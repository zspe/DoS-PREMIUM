## DOS-PREMIUM
A lightweight, CLI-based HTTP Stress Test tool written in Python.
Built by Zed for educational cybersecurity and quick server-load testing.

## Note: This is a DoS (Denial of Service) tool, not a full DDoS. Results vary depending on the target’s server configuration and resilience.


https://github.com/zspe/DoS-PREMIUM/blob/main/Screenshot%202026-09-22%20181425.png?raw=true


# ✨ Features
🚀 Multi-Threaded "Strong" Mode: Use up to 100 concurrent threads to spam the target.
🐢 Single-Threaded "Weak" Mode: Simple request spamming for low-profile testing.
✅ Attack Checker: Verify if the target is down or responding to your load.
🎨 Styled UI: Clean ASCII intro and color-coded terminal output.
⚙️ Auto-URL Handling: Automatically adds http:// if you forget it.
📥 Installation


Install dependencies:
Just run the installer script!
(Or manually: pip install requests colorama beautifulsoup4)

🚀 Usage
Run the script:

Menu Options:

DoS Attack: Enter a URL, choose weak or strong, and set bot count (1–100).
Check Attack: Verify if the target is currently down or responding.
Help/Info: Displays tool details and credits.

🛠️ Tech Stack
Language: Python 3
Libraries: requests, colorama, concurrent.futures, webbrowser
